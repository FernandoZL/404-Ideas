Guía integrada

Todo lo que necesitas saber.

Esta guía está dentro del panel para que no tengas que recordar rutas, nombres de archivos ni comandos de Git.

01

Crear contenido nuevo

En ＋ Nuevo eliges Recuerdo, Carta, Frase, Fecha, Canción, Video o Sorpresa.

  1. Completa los campos.
  2. Adjunta fotos, audio, video o HTML cuando aplique.
  3. Deja apagado Publicar en Nuestro lugar si aún no quieres mostrarlo.
  4. Pulsa Guardar en GitHub.

Resultado: el panel crea la carpeta, el Markdown, sube los archivos y genera un solo Commit.

02

Borrador vs publicado

publicado: false

Se guarda en GitHub, pero no aparece en la web.

publicado: true

GitHub Actions lo incorpora a Nuestro lugar.

Puedes crear algo hoy como borrador y publicarlo días después desde Archivo → Editar → Publicar en la web.

03

Agregar fotos después

  1. Ve a Archivo.
  2. Busca el recuerdo.
  3. Pulsa Editar.
  4. En “Agregar archivos a esta carpeta” selecciona las nuevas fotos.
  5. Pulsa Guardar cambios.

No necesitas reconstruir el recuerdo ni editar GitHub manualmente.

04

Editar algo existente

En Archivo puedes buscar por título, fecha o tipo. Al editar verás el archivo Markdown completo.

  • Guardar cambios: crea un Commit con la edición y archivos nuevos.
  • Publicar / ocultar: cambia publicado y crea otro Commit.
  • Eliminar: elimina el contenido mediante un Commit, con doble confirmación.
05

Inbox: guardar ahora, ordenar después

Usa Inbox cuando solo quieras guardar algo rápido. Puedes escribir una nota y subir cualquier archivo.

Inbox nunca aparece en Nuestro lugar.

07

Commits automáticos

Cada operación importante queda registrada en GitHub:

Guardar borrador: Un momento bonito Publicar: Una carta Actualizar: Un recuerdo Ocultar: Una sorpresa Eliminar: Una frase Guardar en inbox: Algo de hoy

Eso significa que sigues conservando historial y puedes revisar qué cambió en el repositorio.

08

Archivos grandes

El panel limita cada archivo a 90 MiB para evitar que GitHub lo rechace.

Para videos más grandes usa YouTube o espera la fase de optimización.

09

¿Qué hago cuando venza el token?

No tienes que modificar el panel ni el repositorio. Un token vencido no se puede reactivar: simplemente creas otro y lo sustituyes.

  1. Abre GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Crea un token nuevo para 404-Ideas.
  3. Permiso: Contents → Read and write. Metadata puede quedar Read-only automáticamente.
  4. Copia el nuevo github_pat_....
  5. Vuelve al panel. Si el token ya venció, el panel mostrará la pantalla de conexión automáticamente.
  6. Pega el token nuevo y pulsa Conectar.

También puedes usar Cambiar token en la parte superior antes de que venza.
